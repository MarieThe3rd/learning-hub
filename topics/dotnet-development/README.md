# 🟣 .NET Development

Master C#, ASP.NET Core, Entity Framework Core, and the broader .NET ecosystem.

## 🎯 Learning Goals

- [ ] Write idiomatic modern C# (records, pattern matching, nullable reference types)
- [ ] Understand the .NET type system, generics, and LINQ
- [ ] Build Web APIs with ASP.NET Core (controllers and minimal APIs)
- [ ] Apply dependency injection and the built-in .NET DI container
- [ ] Use Entity Framework Core for data access (code-first, migrations, queries)
- [ ] Write unit and integration tests with xUnit and Moq
- [ ] Understand async/await and asynchronous programming patterns
- [ ] Structure .NET solutions following Clean Architecture principles

## 🗺️ Learning Path

### Stage 1: C# Fundamentals
- Types, variables, control flow, methods
- Classes, interfaces, inheritance, polymorphism
- Collections, generics, and LINQ
- Exception handling and null safety

### Stage 2: Modern C# Features
- Records and init-only properties
- Pattern matching (switch expressions, property patterns)
- Async/await and Task-based programming
- Nullable reference types

### Stage 3: ASP.NET Core
- Creating and structuring a Web API project
- Controllers, routing, model binding, and validation
- Dependency injection — registering and resolving services
- Middleware pipeline

### Stage 4: Entity Framework Core
- Code-first modelling and migrations
- Querying with LINQ and EF Core
- Relationships (one-to-many, many-to-many)
- Performance: N+1 queries, eager loading, raw SQL

### Stage 5: Testing & Quality
- Unit testing with xUnit
- Mocking with Moq
- Integration testing with WebApplicationFactory
- Test patterns and test organisation
