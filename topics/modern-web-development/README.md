# 🌐 Modern Web Development

Master the modern web stack — from semantic HTML and responsive CSS to JavaScript, TypeScript, and frontend frameworks.

## 🎯 Learning Goals

- [ ] Write semantic, accessible HTML5
- [ ] Build responsive layouts with CSS Flexbox and Grid
- [ ] Write modern JavaScript (ES2015+) including async/await and modules
- [ ] Add type safety with TypeScript
- [ ] Build interactive UIs with React (or another modern framework)
- [ ] Understand how browsers work (rendering, network, DevTools)
- [ ] Use modern tooling (Vite, ESLint, Prettier, npm)
- [ ] Understand Core Web Vitals and frontend performance

## 🗺️ Learning Path

### Stage 1: HTML & CSS Foundations
- Semantic HTML5 elements and document structure
- CSS box model, specificity, and cascade
- Flexbox for one-dimensional layouts
- CSS Grid for two-dimensional layouts
- Responsive design and media queries

### Stage 2: JavaScript Fundamentals
- Variables, types, functions, and scope
- Arrays, objects, and destructuring
- Promises and async/await
- DOM manipulation and events
- ES modules (import/export)

### Stage 3: TypeScript
- Type annotations, interfaces, and type aliases
- Generics and utility types
- TypeScript with DOM APIs
- Configuring tsconfig.json

### Stage 4: Frontend Frameworks (React)
- Components, props, and JSX
- State with `useState` and `useReducer`
- Side effects with `useEffect`
- Context API and component composition
- React Router for client-side routing

### Stage 5: Tooling & Performance
- Vite for development and bundling
- ESLint and Prettier for code quality
- Core Web Vitals — LCP, CLS, INP
- Lazy loading and code splitting
